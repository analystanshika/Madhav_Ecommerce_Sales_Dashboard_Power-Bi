# Madhav_Ecommerce_Sales_Dashboard_Power-Bi
Interactive Power BI dashboard analyzing Madhav E-Commerce sales, profit, quantity, customer trends, payment methods, and product performance.
## Project Description

Madhav E-Commerce Sales Dashboard is an interactive Power BI project designed to analyze and visualize e-commerce sales performance. The dashboard provides insights into sales, profit, quantity sold, customer purchasing patterns, payment methods, and product categories.

The project focuses on transforming raw sales data into meaningful visualizations and KPIs to make business performance easier to understand and analyze.

### Key Insights
- Total sales and profit performance
- Quantity sold across different categories
- Customer and product-wise sales analysis
- Payment method distribution
- State-wise sales performance
- Monthly sales and profit trends
- Interactive filters for exploring the data

### Tools Used
- Power BI
- Power Query
- DAX
- Excel/CSV Dataset
